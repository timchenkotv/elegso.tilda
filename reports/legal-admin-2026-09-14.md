# Редактор договоров и правовых документов — 14 сентября 2026

## Результат

Установлено на VM 240 (172.16.8.40), сайт https://elegso.ru.
Вход: https://elegso.ru/admin/ → «Договоры и документы».
Код реализации: `9c7b735`; опубликован с виртуальной машины в
`timchenkotv/elegso.tilda` на GitHub.

Перенесены 10 документов и конфигураций: общая оферта, прежняя оферта для
физических лиц, политика обработки персональных данных, cookie, согласие,
судебная практика, настройки оферт, настройки cookie, каталог/подписи кнопок
и существующая страница информации для исполнителей.

Существующие тексты и реквизиты не переписывались. Сравнение опубликованных
JSON с исходниками: 10 из 10 совпадают. История общей оферты содержит три
редакции, прежняя оферта для физических лиц — одну. Снимки остальных
документов зафиксированы при импорте. Неопубликованных изменений в рабочей
базе после установки нет.

## Редактирование

- Названия, описания для поиска, разделы, пункты, порядок, текст и ссылки.
- Даты редакции, вступления в силу и заявленной публикации.
- Идентификатор, постоянный адрес, подписи и пояснения к публикации.
- Каталог, кнопки и карточки документов.
- Судебная практика и технические настройки — через расширенный JSON-редактор.
- SHA-256 вычисляется автоматически; фактический журнал действий неизменяемый.
- Черновик, предпросмотр, подтверждение публикации, статус очереди, история,
  восстановление снимка в новый черновик и защита от параллельного сохранения.

Изменённая оферта получает новую версию и постоянный адрес. Прежние
опубликованные адреса сохраняют свой текст. Дата, указанная в документе,
редактируется отдельно от фактического времени системного события.

Инструкция и техническая структура: [docs/legal-admin.md](../docs/legal-admin.md).

## Хранение и откат

База: `/var/lib/elegso-seo-admin/legal/documents.sqlite3`, закрыта от HTTP.
Копии перед публикациями: `/var/lib/elegso-seo-admin/legal/backups/`.
Копия сайта и конфигурации перед установкой:
`/var/backups/elegso/legal-cms-20260914/`.
Публикации: `/srv/www/elegso.ru/generated-legal/releases/`, действующий указатель
`/srv/www/elegso.ru/generated-legal/current`.

После первого импорта база является источником данных. Развёртывание из Git
пересобирает опубликованные снимки из базы, а не заменяет их исходным JSON.
Публикация атомарная, сбой возвращает прежний выпуск. Перезапуск восстанавливает
незавершённое переключение по идентификатору и контрольной сумме задания.
Деплой не захватывает редакторские задания из очереди и ждёт завершения
работающего издателя до фиксации точки отката.

## Отдельные обнаруженные ограничения

1. Сервер не достигает собственного внешнего адреса `155.212.215.203:443`:
   обращение с VM к https://elegso.ru завершается таймаутом. С внешнего
   подключения те же страницы отвечают HTTP 200; локальный nginx с Host
   `elegso.ru` тоже отвечает 200. DNS с VM указывает на правильный IP.
   Это ограничение внутреннего маршрута к внешнему адресу, не отказ сайта.
   Правила маршрутизации/гипервизора в этой установке не менялись; точная
   причина требует отдельной проверки NAT/firewall.
2. Прежняя страница информации для исполнителей содержит две карточки,
   а не полный встроенный договор. Её существующая внешняя ссылка на
   Яндекс Диск ранее вернула 404 через официальный API. Перенесены именно
   имеющиеся тексты и ссылка, недостающий документ не выдумывался. В редакторе
   можно заменить адрес и тексты карточек; для полного текста нужен исходник.
3. Полный вход в производственную админку через проверочный браузер не
   выполнялся: у браузера нет сохранённой Basic Auth-сессии. Производственный
   API проверен через штатный доверенный Unix-сокет и существующую роль;
   интерфейс и публикация проверены в отдельной тестовой базе.
