# Проверка входящего и исходящего IP сайта

Дата: 13 сентября 2026 года. Машина: VM240, внутренний адрес 172.16.8.40.

| Проверка | Результат |
| --- | --- |
| DNS A elegso.ru | 155.212.215.203 |
| DNS A www.elegso.ru | 155.212.215.203 |
| DNS AAAA elegso.ru | Не опубликована |
| Исходящий IPv4 от queen | 155.212.215.203 |
| Исходящий IPv4 от www-data | 155.212.215.203 |
| Исходящий IPv4 от elegso_api | 155.212.215.203 |
| Исходящий IPv4 от elegso-seo-admin | 155.212.215.203 |
| Исходящий IPv4 от seo-monitor | 155.212.215.203 |
| Маршрут VM до внешнего адреса | Через 172.16.8.1, eth0, источник 172.16.8.40 |
| Геобаза IPinfo для внешнего адреса | Moscow, Moscow, RU, AS50340 JSC Selectel, Europe/Moscow |
| Исходящий IPv6 | Соединение отсутствует, маршрут по умолчанию IPv6 не обнаружен |
| Proxy-переменные работающих процессов калькулятора и SEO-админки | Не обнаружены |
| Proxy-переменные в env-файле SEO-монитора | Не обнаружены |
| SEO-монитор | Периодический сервис; во время проверки между запусками, timer включён |

Внешний адрес проверялся прямыми HTTPS-запросами с VM под указанными служебными пользователями. Значения секретов env-файлов и окружений не выводились.

Итог: в проверенном серверном контуре исходящий IPv4 совпадает с входящим публичным адресом сайта. Геобаза определяет его как московский. Оснований менять сеть не обнаружено; изменения маршрутов, NAT, VPN или прокси не выполнялись.

Геолокация IP в сторонней базе не является доказательством физического размещения всех баз и резервных копий, не определяет автоматически регион сайта в Яндекс Вебмастере и не доказывает причину изменения поисковых позиций. Исходящий адрес самой виртуальной машины отдельно проверен от IP браузера посетителя и от внешних исследовательских инструментов.
