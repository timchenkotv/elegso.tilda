## Страницы и индексация

| Страница | Режим |
| --- | --- |
| `/oferta/` | Полный текст для организаций и ИП, index/follow |
| `/oferta-fiz/` | Полный текст для потребителей, index/follow |
| `/oferta/history/` | История деловой оферты, index/follow |
| `/oferta-fiz/history/` | История потребительской оферты, index/follow |
| `/oferta/versions/2026-09-13/` | Постоянная копия, noindex/follow |
| `/oferta-fiz/versions/2026-09-13/` | Постоянная копия, noindex/follow |

В поиске предлагаются текущие тексты и страницы истории. Постоянные копии доступны без авторизации, но исключены как дубли. Это не ограничивает чтение и печать договора. Индексация разрешена технически; решение о включении в выдачу и срок обхода принимает поисковая система.

Каждая основная страница содержит весь текст без загрузки из API и без зависимости от JavaScript, H1, описание, canonical и структурированные данные. Основные страницы и история добавлены в sitemap. На существующих страницах добавлена отдельная полоса со ссылками в подвале; прежний дисклеймер уточнён, чтобы не отрицать существование оферт. Новые статьи и кейсы наследуют этот подвал из общего шаблона.
